# 🌟 tungol-gfx

A lightweight 3D rendering library built on Vulkan.

| | |
| :--- | :--- |
| **Graphics API** | `Vulkan 1.3+` |
| **Dependencies** | `GLFW` |
| **Supports** | `PCF shadow Map` · `Compute Skinning` · `simple single-light PBR` |
